# 室分报告工具（Ssv-Semi-Automatic）

> **5G SA 网络性能验收报告自动生成工具**
> 截图裁剪 → OCR 文字识别 → 数据提取 → 图片排版插入 Excel 模板 → 输出验收报告
> 无需安装 Python，双击即用（Windows 10/11 64 位）

---

# 软件使用说明

适用版本：Windows 10/11 64 位 · 无需安装 Python

---

## 1. 软件简介

本工具用于 **5G SA 网络性能验收报告** 的自动生成。只需把现场测试截图放入指定文件夹、点一下"开始执行"，即可自动完成：

> 截图裁剪 → OCR 文字识别 → 数据提取 → 图片排版插入 Excel 模板 → 生成验收报告

全程无需手工抄录数据、无需手工调整图片位置。

---

## 2. 安装与部署

### 2.1 目录结构

将整个 `发布版` 文件夹拷贝到电脑任意位置（如 `D:\报告工具\`），保持内部结构不变：

```
发布版/
├── 报告生成工具.exe     ← 双击运行
├── _internal/           ← 程序运行组件（勿动）
├── libs/                ← 依赖库（勿动）
├── PaddleOCR-json/      ← OCR 识别引擎（勿动）
├── license.lic          ← 授权文件
└── 部署说明.md
```

> ⚠️ **四个文件夹缺一不可**，请勿单独移动 exe 或删除任何目录。

### 2.2 启动

双击 `报告生成工具.exe` 即可，无需安装任何东西。

## 3. 授权激活

1. 双击运行程序，若未授权会弹出窗口显示**本机机器码**
2. 将机器码发送给软件提供方

## 4. 使用前准备（关键！）

### 4.1 建立工作目录

程序默认工作目录为 `D:\baogao\sferzaibo`，可在界面"工作目录"处修改或浏览选择。
工作目录下需准备（程序会自动创建子目录）：

| 子目录/文件 | 作用 |
|---|---|
| `ping\` | 放 ping 测试原始截图（自动裁剪用） |
| `pictuer\` | 放主数据（CQT）原始截图（自动裁剪用） |
| `dt\` | 放遍历测试图（DT），按编号建子文件夹 |
| `室分模板.xlsx` | **Excel 报告模板**（重要，见 4.3） |
| `jietu\`、`result.xlsx`、`finish.xlsx` | 程序自动生成 |

### 4.2 截图命名规范（用于插入报告）

程序按文件名自动匹配图片，**必须按下表命名**：

**① 主数据整图（放入 `pictuer\`，组号从 1 开始）**

| 文件名 | 含义 |
|---|---|
| `1hd.png`、`2hd.png`… | 第 N 组 HD 图 |
| `1hu.png`、`2hu.png`… | 第 N 组 HU 图 |
| `1cd.png`、`2cd.png`… | 第 N 组 CD 图 |
| `1cu.png`、`2cu.png`… | 第 N 组 CU 图 |

**② ping 截图（放入 `ping\`）**

| 文件名 | 含义 |
|---|---|
| `1ping32.png`、`2ping32.png`… | 第 N 组 ping32 图 |
| `1ping2000.png`、`2ping2000.png`… | 第 N 组 ping2000 图 |

**③ 遍历测试图（放入 `dt\`，按编号建文件夹）**

```
dt\1\RSRP.png   dt\1\SINR.png   dt\1\PCI.png   dt\1\DL.png   dt\1\UL.png
dt\2\RSRP.png   ...（依此类推）
```

> 以上是**插入报告**用的整图；`ping\` 和 `pictuer\` 里的**原始截图**（用于裁剪+OCR）文件名可随意，但要和整图对应同组测试。

### 4.3 Excel 模板

- 模板文件名为 `室分模板.xlsx`，放在工作目录下
- 需包含两个工作表（名称可在界面"运行参数"中修改）：
  - `SA-网络性能验收-CQT`（主数据 + ping 报告页）
  - `SA-网络性能验收-遍历测试图`（DT 报告页）
- 图片按界面配置的行列位置自动插入，模板只需做好表头/格式

## 5. 界面操作指南

### 5.1 顶部工具栏

- **▶ 开始执行**：按顺序执行全部六个步骤
- **■ 停止**：停止当前任务（当前步骤完成后生效）
- **配置方案**：保存/另存为/删除界面参数（见第 7 节）
- **工作目录**：设置数据所在目录（默认 `D:\baogao\sferzaibo`）

底部状态栏实时显示进度百分比与当前步骤。

### 5.2 标签页① 数据位置（裁剪坐标设置）

设置截图裁剪区域坐标（左上 x1,y1 → 右下 x2,y2）：

- **Ping 范围**：delay（延迟）、jitter（抖动）两个区域
- **主数据范围**：pindian_1/2（频点）、rsrp_1/2、sinr_1/2、dl、ul 共 8 个区域
- 可**加载一张截图预览**，鼠标点击两个点（绿点→红点）框选区域后点"填入选中行"，自动填坐标
- 支持双击表格直接编辑坐标、添加/删除行

> 不同手机型号/分辨率截图位置不同，首次使用请用预览功能校准坐标。

### 5.3 标签页② 数据摘取（OCR 与数据筛选）

- **目标频点前缀**（默认 `525150`）：只保留频点以此开头的点位数据
- **前缀长度**（默认 6）：频点前几位参与匹配
- **仅提取数据**：不重新 OCR，直接从已有的 `result.xlsx` 提取到 `finish.xlsx`
- **并发引擎数**（默认 3）：OCR 同时启动的引擎数；每个引擎占 300~600MB 内存，
  内存小的电脑建议设 1~2，内存大的可提高到 4~6 加快速度

### 5.4 标签页③ 图片插入（排版参数）

三个子页分别配置三类图片插入模板的位置与大小：

| 子页 | 参数 | 默认值 |
|---|---|---|
| 主数据截图 (CQT) | 每组起始行、hd/其他图宽高(cm)、列配置 | 起始行 6，间隔 22；hd 10.2×12.8cm，其他 8.7×12.8cm；列 `hd,AC hu,AT cd,BK cu,CB` |
| Ping 截图 (CQT) | 起始行、行间隔、宽高、列配置 | 起始行 6，间隔 22；8.6×8.5cm；列 `ping32,CS ping2000,DJ` |
| 遍历测试图 (DT) | 起始行、行间隔、宽高、列配置 | 起始行 7，间隔 18；10.2×7.79cm；列 `RSRP,C SINR,I PCI,AA DL,O UL,U` |

- **列配置格式**：`后缀,列号` 用空格分隔，如 `hd,AC hu,AT`
- 修改参数后点**"刷新图片位置列表"**生成明细
- 下方"图片位置详情"表格**每行一张图**，可双击修改单元格/宽高（高级用户用）

> 图片尺寸单位为 **厘米**，程序按 96 DPI 物理缩放后插入，任何电脑打开显示大小一致。

### 5.5 标签页④ 运行参数

- **Excel 模板文件**：可浏览选择其他模板（留空则用工作目录下 `室分模板.xlsx`）
- **CQT / 遍历测试工作表名**：模板中对应的工作表名称
- **主数据/Ping 截图组数**（默认 4）：本次报告插入的组数
- **DT 起始/结束编号**（默认 1~6）：遍历测试图文件夹编号范围

## 6. 标准操作流程（从截图到报告）

1. **整理数据**：把截图按第 4 节规范放入 `ping\`、`pictuer\`、`dt\`，模板放入工作目录
2. **打开软件**，设置工作目录（如默认路径与数据位置一致可跳过）
3. **首次使用**：在"数据位置"标签页校准裁剪坐标（加载截图取点）
4. 确认"数据摘取"的频点前缀正确（默认 525150 一般不用改）
5. 确认"图片插入"和"运行参数"的组数、编号正确
6. 点击 **▶ 开始执行**，等待进度到 100%（OCR 阶段较慢，视图片量而定）
7. 完成后打开工作目录下的 `室分模板.xlsx` 检查报告：
   - CQT 表：主数据截图、ping 截图已按位置插入
   - 遍历测试图表：DT 图已插入
   - `finish.xlsx`：数据提取结果（Sheet1 频点数据、Sheet2 ping 数据）

## 7. 配置方案管理

界面参数（裁剪坐标、列配置、尺寸等）可保存为方案，换项目/换机型时一键切换：

- **保存**：把当前界面参数保存到当前方案名
- **另存为...**：以新名称保存一套参数（如"华为Mate60"、"苹果15"）
- **删除**：删除选中方案（"默认"方案不可删）
- 方案自动保存在 exe 同目录 `gui_profiles.json`，关闭软件时自动记录上次使用的方案

## 9. 常见问题

| 问题 | 处理 |
|---|---|
| 双击无反应/启动失败 | 查看 exe 同目录 `运行日志.log` 最后几行，把内容发给提供方 |
| 弹窗提示授权失败 | 把弹窗中的机器码发给提供方，换取新 `license.lic` |
| 日志停在"验证授权..." | 授权弹窗在等待：确认 `license.lic` 已放入 exe 同目录 |
| OCR 识别失败 | 确认 `PaddleOCR-json` 目录完整（含 exe 和 models 文件夹） |
| 识别出乱码/错字 | 截图过小或模糊：裁剪区域坐标重新校准；提高截图清晰度 |
| 频点数据为空 | 检查"目标频点前缀"是否与测试频点一致；裁剪区域是否包含频点 |
| 图片没有插入 | 检查图片文件名是否符合第 4.2 节命名规范（如 `1hd.png`） |
| 电脑卡顿/内存不足 | "数据摘取"页把 OCR 并发引擎数调小（1~2） |
| 图片在别人电脑上大小变了 | 图片尺寸以厘米为单位物理缩放，理论上任何端一致；确认未改动 `libs` |

## 开发/构建

本仓库为源码仓库，包含：

| 文件 | 说明 |
|---|---|
| `sferzaibo.py` | 主程序源码（OCR 引擎调用、数据提取、Excel 报告生成、GUI） |
| `build_pkg/main.py` | 打包入口（统一日志、外部依赖加载、高 DPI） |
| `build_pkg/report.spec` | PyInstaller 打包配置（收集全部标准库） |
| `build_libs.py` | 外部依赖库构建工具 |

构建流程（需 Python 3.13 + VS2022）：
1. `python -m nuitka --mode=module --output-dir=dist_pyd sferzaibo.py` 编译机器码模块
2. `python -m PyInstaller build_pkg/report.spec` 打包 exe
3. 组装 `dist\发布版\`（exe + libs + PaddleOCR-json + license.lic）

> 注：`private_key.pem`、`license.lic` 等敏感文件不入库，请本地保管。
